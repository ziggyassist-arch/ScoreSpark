# ScoreSpark Phase 2 — Efficient Build Plan

## Batch 1: Core Functionality (must work perfectly)
These are the basics that every user will hit first. If these break, nothing else matters.
1. Search bar — find teams/players/leagues instantly
2. Dark/light mode toggle — actually functional
3. Team form guide — W/W/L/D/W visual badges on standings pages
4. League-specific top scorers + assists — per league, not just overall

## Batch 2: Match Experience (what keeps users engaged)
5. Lineups/formations — starting XI with formation diagram (soccer)
6. Live match commentary — minute-by-minute text updates
7. Player ratings — post-match ratings per player (soccer)
8. Match momentum tracker — visual pressure/momentum indicator

## Batch 3: Pre-Match & Transfers (discovery features)
9. Predicted lineups — pre-match predicted XI
10. Transfer news/rumors section
11. Push notification wiring — goal alerts, match start, final score

## Batch 4: Polish
12. Fix any remaining UI issues from Matt's earlier feedback
13. Ensure iOS parity with web features
14. Performance optimization
